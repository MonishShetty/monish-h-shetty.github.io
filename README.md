# Monish H Shetty — Portfolio

A single-page portfolio for Monish H Shetty, focused on integration engineering, platform systems, cloud, and AI-assisted developer workflows.

The selected-builds section also highlights the Exelon Circuits company website and Hauteze e-commerce platform, both built during Monish's frontend internship.

## Stack

- Semantic HTML
- Modern CSS with responsive layouts and motion
- Vanilla JavaScript for pointer glow, scroll reveals, and navigation
- GitHub Pages-compatible static deployment

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server.

## Deploy

Enable GitHub Pages for the repository and select the `main` branch as the source.
