Software Engineer 2

Elsevier · Remote

Owning design, delivery, and production support for enterprise integrations across multi-tenant research management platforms.

  • Designed and implemented a two-level, run-scoped Caffeine caching architecture with SHA-256 request fingerprints, canonical JSON keys, duplicate-request protection, configurable TTL cleanup, exception-safe handling, and per-endpoint hit/miss/store metrics — reducing repeated external API calls by approximately 40%.

  • Prototyped a Jira-to-PR automation tool that generates implementation plans and code diffs via Claude AI, validates and applies patches deterministically, runs tests, and opens pull requests with approval gates and credential safeguards.
  • Architected reusable shared libraries for fuzzy matching, person/organization deduplication, onboarding utilities, and synchronization components, published as versioned artifacts across multiple integration projects.
  • Worked on platform modernization with Java 21 upgrades, CI/CD hardening, short-lived AWS credentials, ArgoCD deployments, production approval gates, and PR quality standards.
  • Expanded production ownership through CloudWatch monitoring, alerting, incident investigation, and operational runbooks for enterprise clients.
